# Arkansas Tobacco Retail Configuration

R code for measuring the spatial configuration of tobacco retail in Arkansas (type-specific proximity, diversity, specialty access, and food-tobacco bundling) and for analyzing its associations with tobacco use, cancer, and cardiometabolic health.

Maintained by Michael Niño, PhD, Department of Sociology and Criminology, University of Arkansas.

## Status

Code and documentation will be posted here as analyses are completed, and no later than the time of the associated publication. Each release will be archived in Zenodo with a digital object identifier (DOI).

## Contents

This repository will include R code to construct the configuration measures from a tobacco permit roster and business listings, the analysis code, and the retailer classification protocol.

This repository contains code and documentation only. It does not include survey responses, respondent locations or coordinates, respondent-level exposure measures, or licensed commercial business listings.
